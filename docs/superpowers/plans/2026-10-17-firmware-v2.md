# Firmware v2 Implementation Plan

> Executed natively in the same session (user: "пиши код"), no separate plan review.

**Goal:** firmware runs on PCB v2: new pins, LSM6DS3TR-C, LED power switch with current latch, VBAT, K-line DS2 as a data source.

**Architecture:** existing modules edited in place. Pure logic (DS2 framing/decoding, latch timing) lives in `lib/ds2` and `lib/power_latch` without Arduino deps so it is unit-tested with `pio test -e native`. Hardware glue in `src/power/` and `src/kline/`.

**Tech Stack:** PlatformIO, espressif32@6.8.0 Arduino, FastLED, GyverHub, Unity (native tests).

**Spec:** `docs/superpowers/specs/2026-10-17-firmware-v2-design.md`

## Global Constraints
- v2 only, no `#ifdef` per board.
- Settings FileData key bumps 'B' -> 'C'.
- DS2: MS43 addr 0x12, 9600 8E1, status request `12 05 0B 03 1F`, len byte = whole frame.
- MS43 0B03 offsets from `ms430ds0_ds2.b1v` (github radelbro/BimmerDis): N byte3 u16be, VS byte5, PVS_AV byte6 u16 *0.0018311, TPS byte8 u16 *0.0018311, TIA byte12 *0.75-48, TCO byte13 *0.75-48, VB byte43 *0.10156.
- Test vector (drive2.ru/l/9797918): `12 2D A0 02 EB 00 00 00 00 00 00 31 6F 9A 82 74 BE 01 EC FE 66 54 F4 8A 78 88 78 90 78 1E FE FE 34 34 10 CB 0E C6 05 05 0D 2E D1 87 BD` -> 747 rpm, TIA 35.25, TCO 67.5, VB 13.71, xor ok.
- IS: amps = V * 22700 / 470; VBAT = V * 5.7.

## Review Focus
1. DS2 reply arriving in pieces across ticks -> parser is byte-fed, test feeds byte by byte.
2. No echo / wrong echo (JP2 open, no 12 V) -> BAD_ECHO or timeout, counters grow, loop never blocks.
3. Garbage before the reply header -> parser skips until 0x12.
4. WS2815 inrush spike < 100 ms at switch-on -> no latch.
5. NACK (0xB0) or short frame -> decode returns false, vehicle data untouched.

## Tasks
1. `lib/ds2` (checksum, build, byte parser with echo skip + resync, MS43 status decode, hex parse, pedal %), `[env:native]`, `test/test_ds2`.
2. `lib/power_latch` (conversions, overcurrent/fault debounce), `test/test_power`.
3. Port: `pins.h` v2, drop gps/telegram + libs, CAN pins, LED strip6Out removal, 12 V power model, GRB default, settings key 'C' + `ledMaxAmps`, canMode 0..3. Build + flash + boot log.
4. IMU LSM6DS3TR-C in `imu.cpp`. Flash, WHO_AM_I + tilt check.
5. `src/power/` (switch, latch, VBAT, status LED), first-black-frame flag in LED task, hub System rows. Flash, check VBAT/current.
6. `src/kline/` + `CAN_MODE_DS2` in vehicle + hub DS2 section with custom request. Flash, check echo/timeouts.
7. Docs: README firmware notes, PCB/v2/README, vault NOTES.
