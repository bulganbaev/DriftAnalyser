# DriftAnalyser (ZverCustomLed)

Прошивка для платы на ESP32-S3, которая управляет шестью адресными лентами WS2812B по данным с машины. Данные берутся с CAN-шины (OBD2 или пассивно с BMW MS43) и со встроенного гироскопа/акселерометра MPU-6050. Настройка через веб-интерфейс GyverHub, который отдаётся с самой платы по Wi-Fi, приложение не нужно.

## Железо

Плата своя, файлы в `PCB/` (EasyEDA-схема, гербер, BOM, pick-and-place).

| Узел | Что стоит |
|---|---|
| Контроллер | ESP32-S3-WROOM-1 N16R2 (16 МБ флеш), USB-C на native USB |
| CAN | TJA1050, пин S (silent) управляется из прошивки |
| IMU | MPU-6050, I2C: SDA IO8, SCL IO9, подтяжки R2/R3 |
| Ленты | 6 разъёмов LED1..LED6, данные через сдвигатели TXB0108 |
| Питание | вход 12 В (PWR), 7805 → VBUS → AMS1117 3.3 В; USB через L6 на ту же шину VBUS, диод D3 отделяет 7805 |
| Реле | 2 × HF49FD, в прошивке пока не задействованы |
| SD | слот TF, не задействован |
| GPS | посадочное место под NEO-6M, не запаян |

### Пины (`src/pins/pins.h`)

| Сигнал | GPIO |
|---|---|
| LED 1 | 10 |
| LED 2 | 21 |
| LED 3 | 41 |
| LED 4 | 42 |
| LED 5 | 14 |
| LED 6 | 40 |
| CAN RX | 16 |
| CAN TX | 35 |
| CAN STB | 15 |
| IMU SDA | 8 |
| IMU SCL | 9 |
| BOOT | 0 |

На плате шелкография LED3 и LED5 перепутана, в коде пины уже поменяны местами. Разъём LED3 на плате это GPIO41, LED5 это GPIO14.

### Перемычки

- H2..H7 — питание для каждой ленты LED1..LED6, три пина: 12V / VCC_LED_n / +5V. Перемычка выбирает, что подаётся на пин питания разъёма.
- H1 — терминатор 120 Ом между CANH и CANL. При подключении к шине машины снять, там свои терминаторы.

### Известные проблемы платы

- **5-вольтовые ленты нельзя питать с платы.** Шина +5V идёт от линейника 7805 (1.5 А максимум, без радиатора реально ~0.5 А), с неё же питается сам ESP. Лента на смене цвета роняет 5 В, ESP уходит в brownout. Для 5 В лент ставить внешний DC-DC 12→5 В на 5–10 А, землю объединить с платой, в разъём заводить только DATA и GND. Или брать 12 В ленты (WS2815) и перемычку на 12V.
- **MPU-6050: обвязка не дорисована.** По схеме у конденсатора C8 (REGOUT) и резистора R7 (AD0) по одной площадке висит в воздухе. Без C8 на землю внутренний стабилизатор чипа нестабилен, чип отвечает через раз; без R7 на землю адрес плавает между 0x68 и 0x69. Нужны две перемычки: свободный пятак C8 → GND, свободный пятак R7 → GND. Прошивка ищет чип на обоих адресах и переинициализирует его при потере.
- **USB и 12 В одновременно** допустимы (D3 не даёт USB залезть в 12-вольтовую часть), но только если лента не висит на +5V платы.

## Сборка и прошивка

PlatformIO, окружение `esp32s3box`.

```
~/.platformio/penv/bin/pio run -e esp32s3box            # сборка
~/.platformio/penv/bin/pio run -e esp32s3box -t upload  # заливка
~/.platformio/penv/bin/pio device monitor -b 115200     # монитор
```

Если `pio` есть в PATH, полный путь не нужен. В VS Code то же самое кнопками PlatformIO в статус-баре.

Плата видна как `/dev/cu.usbmodemXXXX` (native USB CDC), лог на 115200. При открытии порта плата может сброситься по DTR/RTS, это нормально.

Важное в `platformio.ini`:

| Параметр | Зачем |
|---|---|
| `board_build.partitions = default_16MB.csv` | под прошивку 6.5 МБ вместо дефолтных 1.3 МБ |
| `-D GH_INCLUDE_PORTAL` | веб-интерфейс GyverHub зашит в прошивку и отдаётся с платы |
| `-D GH_NO_STREAM` | GyverHub не льёт свои пакеты в Serial |
| `-D FASTLED_ESP32_FLASH_LOCK=1` | запись во флеш ждёт окончания вывода на ленты, иначе паника `Cache disabled but cached memory region accessed` |

Библиотека GyverHub тянется с git HEAD (репозиторий заархивирован), магазинные приложения с ней несовместимы (`Device has newer API`). Поэтому интерфейс встроен в прошивку.

### Дефолтная Wi-Fi сеть

Скопировать `src/config/secrets.example.h` в `src/config/secrets.h` и вписать SSID и пароль. Файл в `.gitignore`. Эти значения используются как стартовые при чистом файле настроек, потом меняются из интерфейса.

## Wi-Fi

- При старте плата подключается к сохранённой сети (STA).
- Если за 20 с не подключилась, поднимает свою точку `ZverCustomLed` / `qwerty12345`, IP 192.168.4.1, и продолжает пробовать STA каждые 30 с.
- Как только STA подключилась, точка гасится. Если STA пропала на 20 с, точка поднимается снова.
- Пустой SSID = только своя точка.
- Веб-интерфейс: `http://<ip платы>`, на точке `http://192.168.4.1` (открывается как captive portal). Только http.
- OTA-прошивка и файловый менеджер доступны во вкладке информации об устройстве в интерфейсе GyverHub.

## Веб-интерфейс

Меню сверху, шесть страниц.

### Dashboard

Главный выключатель Master, статус Wi-Fi, gauge RPM / Speed / Temp / Throttle / Lateral G / Yaw, статус CAN, кнопка Reboot.

### LEDs

Настройки выбранной ленты (Strip 1..6):

| Настройка | Что делает |
|---|---|
| Strip N enabled | вкл/выкл вывод на ленту |
| Reverse | перевернуть направление |
| Mode | Animation / Scale / Hybrid |
| Scale source | RPM / Speed / Throttle / Lateral G / Yaw rate (для Scale и Hybrid) |
| Animation | одна из 16 анимаций (для Animation, а в Hybrid — то, что крутится ниже минимума) |
| Color | цвет для одноцветных анимаций |
| Strip brightness | яркость ленты 0–100 |
| LED count | число светодиодов, 1..1000, применяется на лету |
| Color order | RGB / GRB / BGR / RBG / GBR / BRG, тоже на лету |
| Grow from middle + Middle LED | шкала растёт от указанного светодиода в обе стороны; для G и Yaw знак значения выбирает сторону |
| Apply to all strips | скопировать настройки этой ленты на остальные (кроме числа светодиодов) |

Режимы: Animation — просто анимация. Scale — шкала по выбранному источнику, семь цветовых зон от синего к пурпурному. Hybrid — шкала, когда источник выше минимума, иначе анимация.

Анимации: Static Color, Theater Chase, Color Wave, Breathing Light, Rainbow Cycle, Snake, Meteor Rain, Twinkle, Running Lights, Larson Scanner, Fire, Police, Confetti, Color Wipe, Sinelon, G Force. У каждой ленты своё состояние, две ленты на одной анимации друг другу не мешают.

Глобальные:

| Настройка | Что делает |
|---|---|
| Animation speed | частота кадров для всех анимаций (у Police и Sinelon ещё и период) |
| Global brightness | общая яркость 0–100 |
| Scale min / max RPM | диапазон шкалы по оборотам |
| Shift light RPM / Shift color | выше этого порога вся лента в режиме шкалы по RPM мигает выбранным цветом; 0 = порог равен max RPM |
| Full scale km/h / G / yaw | полная шкала для источников Speed, Lateral G, Yaw |
| Engine off / no data | что делать, когда мотор заглушен или данных нет: Keep running / Dim (до Dim to %) / Off |
| Power limit mA | лимит тока FastLED при 5 В, 0 = выключен |
| Presets | три слота, Save / Load всего набора настроек лент и глобальных |

«Мотор заглушен» = нет свежих данных с CAN или обороты ниже 300.

### CAN

Выбор источника OBD2 / BMW MS43 / Sniffer (переключается на лету, драйвер перезапускается), статус драйвера и потока, сырые значения RPM / Speed / Temp / Throttle. В режиме Sniffer — таблица кадров по ID, обновляется раз в секунду.

### Wi-Fi

SSID, пароль, кнопка Reconnect, статус, IP и RSSI в сети, состояние своей точки, MAC.

### IMU

Gauge Lateral G и Yaw, выбор осей (±X / ±Y / ±Z) для поперечного ускорения и для угловой скорости, кнопка Calibrate (машина ровно, мотор заглушен — текущее показание становится нулём, смещения сохраняются), сырые значения по трём осям и температура чипа.

### System

Uptime, причина последнего сброса, свободная память, дата сборки, занятость файловой системы, хвост лога, кнопки Refresh log / Clear log / Reboot.

## CAN

Скорость 500 кбит/с во всех режимах.

**OBD2.** Активный опрос mode 01 на 0x7DF, ответ ждётся с 0x7E8..0x7EF. PID 0x0C (RPM), 0x0D (скорость), 0x11 (дроссель), 0x05 (температура ОЖ), по кругу, пауза 50 мс между запросами, таймаут ответа 200 мс. Неблокирующий.

**BMW MS43.** Плата в listen-only, ничего не передаёт и не подтверждает кадры. Декодирует:

| ID | Данные | Формула |
|---|---|---|
| 0x316 (DME1) | обороты | `((b3 << 8) \| b2) / 6.4` |
| 0x329 (DME2) | температура ОЖ, дроссель | `b1 * 0.75 - 48`, `b5 * 100 / 254` |
| 0x153 (ASC1) | скорость | `((b2 << 8) \| b1) / 128` — не проверено, калибровать по дампу |

У MS43 диагностика по K-line, OBD2-запросы он не понимает. CAN между DME, приборкой, ABS и АКПП выведен на разъём X60004: пин 36 = CAN H (жёлто-красный), пин 37 = CAN L (жёлто-коричневый). Масса платы на кузов, H1 снять.

**Sniffer.** Listen-only, все кадры в таблицу по ID (до 64 ID): длина, последние байты, кадров в секунду, всего. Та же таблица печатается в Serial не чаще двух раз в секунду на ID.

Если данных нет 3 с, обороты, скорость и дроссель сбрасываются в 0, температура остаётся.

## Хранение настроек

Всё в LittleFS, файл `/settings.dat` через FileData. Буква-ключ в `src/settings/settings.cpp` (сейчас `'B'`) работает как версия структуры: при изменении `SavedData` или буквы файл перезаписывается дефолтами. Запись отложенная, через `fileData.update()` после изменений в интерфейсе.

Лог `/log.txt`: старт с причиной сброса и датой сборки, Wi-Fi подключился/пропал, точка поднялась, смена режима CAN, найден/потерян IMU, перезагрузки из интерфейса и по OTA. При 24 кБ переезжает в `/log.old`. Файлы можно скачать через файловый менеджер GyverHub.

## Известные проблемы и что дальше

- Формула скорости для 0x153 взята с форума и не проверена, сверять по сниффер-дампу на ходу.
- MS43-декодер на живой машине ещё не гонялся, начинать со Sniffer и смотреть, что летит.
- Ориентация IMU зависит от того, как плата стоит в машине: выбрать оси на странице IMU и откалибровать на ровной площадке.
- MPU-6050 без перемычек на C8 и R7 работает нестабильно.
- GPS не запаян и в прошивке не используется.
- Реле и SD-карта не задействованы.
- Аккуратнее с яркостью 100 при 5 В лентах на линейнике платы, см. раздел про питание.
