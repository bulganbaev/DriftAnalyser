# ZVER L8（hw rev 3）— 下单说明

文件：`gerbers.zip`（Gerber + Excellon 钻孔，原点为板子左下角）、`BOM-cn.csv`、`CPL.csv`（坐标文件，mm，元件中心）。

## 板子参数

| 项目 | 要求 |
| --- | --- |
| 尺寸 | 55 × 112 mm，R3 圆角，4 × M3 安装孔（3.2 mm 非金属化） |
| 层数 | 6 层，板厚 1.6 mm |
| 铜厚 | 外层 1 oz，**内层 1 oz（不是 0.5 oz）** |
| 表面处理 | **沉金 ENIG** |
| 阻焊 / 丝印 | 绿油白字（颜色不限） |
| 最小线宽/线距 | 0.2 / 0.2 mm（U2 焊盘间 0.13 mm） |
| 最小孔 | 0.2 mm（仅 ESP32 模块散热孔），全部通孔，无盲埋孔 |
| **压接孔** | **J2、J5 共 32 个孔，成品孔径 1.475 ±0.05 mm**（钻孔 1.60，孔铜 25–60 µm）。普通 ±0.08 公差不够，请按压接孔控制 |

## 贴装说明

- 所有元件都在顶层，底层无元件。
- U10–U13（BTS7008-2EPA，TSDSO-14）、U7（LMR36520，HSOIC-8）、Q1/Q2（TDSON-8）底部有散热焊盘，**焊盘要上锡膏**，不能只焊引脚。
- U3（LSM6DS3TR-C，LGA-14，0.5 mm 间距）是板上最细的间距。
- 坐标文件角度为 KiCad 原始角度，贴片前请核对方向（SOT/SOIC 可能相差 90°/180°）。
- 压接端子请在回流焊之后压入。
